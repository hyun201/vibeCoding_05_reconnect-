# Re:Connect 동창회 초대장 구현 개요

본 문서는 2032년 10월 1일 창경궁에서 열리는 동창회 초대장(Re:Connect) 프로젝트에 대한 전반적인 구현 계획, 작업 목록 및 기능 워크스루를 담고 있습니다.

---

## 📋 1. 구현 계획 (Implementation Plan)

**프로젝트 목표:** 
2032년 10월 1일 창경궁에서 열리는 동창회를 위한 모바일 중심의 우아하고 고급스러운 웹 초대장을 제작한다.

**디자인 및 기술 전략:**
*   **Aesthetic (미적 방향성):** 어두운 톤의 배경(Dark Theme)에 골드 포인트 컬러(`var(--gold)`)를 사용하여 고급스러움과 무게감을 동시에 잡음. Noto Serif KR 폰트를 사용해 우아한 타이포그래피 구현.
*   **동적 상호작용 (Interactive):** 정적인 페이지를 피하고, 캔버스를 활용한 흩날리는 입자 효과(Particles), 스크롤에 반응하여 나타나는 페이드 인(Scroll Reveal), 부드러운 슬라이더 애니메이션 등을 적용해 생동감 있는 경험 제공.
*   **구조:** 
    1. Hero (도입부)
    2. Photo Slider (추억 사진첩)
    3. Countdown (디데이 타이머)
    4. Map (오시는 길)
    5. Footer (참석 여부 전달)

## ✅ 2. 작업 목록 (Task List)

### [ 핵심 구조 및 스타일링 ]
- [x] HTML5 문서 기본 뼈대 구성 및 반응형 메타 태그(`viewport`) 적용
- [x] Google Fonts (Noto Serif KR, Noto Sans KR) 연동
- [x] `style.css`에 글로벌 색상 변수(골드, 다크 톤) 지정 및 레이아웃(flex/grid) 세팅

### [ 컴포넌트별 기능 구현 ]
- [x] **Hero (메인 배너):** 커스텀 SVG 엠블럼과 우아한 텍스트 서식, 하단 스크롤 힌트 애니메이션 구현
- [x] **Background Particles (배경):** `script.js` 내 `<canvas>` API를 활용해 위로 떠오르는 금빛 입자 효과 렌더링
- [x] **Photo Slider (사진첩):** 좌우 화살표 및 하단 인디케이터(Dots) 연동, 4초 주기 자동 슬라이드, 모바일 터치 스와이프 기능 적용
- [x] **Countdown (디데이):** 2032년 10월 1일 기준 남은 일/시간/분/초 실시간 계산, 숫자가 변경될 때 플립(Flip) 애니메이션 구현
- [x] **Map (지도):** 창경궁 Google 지도 iframe 삽입 및 정확한 네이버 지도 장소 검색 링크 버튼(수정 완료) 적용
- [x] **Footer (푸터):** 하단 그라데이션 배경 처리 및 메일(`mailto:`) 기반의 RSVP(참석 여부 회신) 버튼 호버 애니메이션 구현
- [x] **Scroll Reveal (등장 애니메이션):** `IntersectionObserver` API를 활용하여 사용자가 화면을 내릴 때 각 섹션이 부드럽게 나타나는 효과(순차적 등장 포함) 적용

## 🚶 3. 워크스루 (Walkthrough)

전체 웹사이트는 사용자 경험을 극대화하기 위해 HTML/CSS/JS 세 가지 요소가 유기적으로 결합되어 있습니다.

1. **시각적 첫인상 (Canvas Particles & Hero)**
   *   방문자가 페이지에 접속하면 가장 먼저 `script.js`의 `createParticle()` 로직이 실행되어 40개의 금빛 입자가 배경에서 은은하게 흩날립니다.
   *   동시에 `Hero` 섹션의 타이포그래피("Re:Connect")와 중앙 엠블럼이 시선을 사로잡으며 행사의 분위기를 전달합니다.
2. **스크롤 반응형 애니메이션 (Intersection Observer)**
   *   페이지를 아래로 스크롤하면 `style.css`의 `.reveal` 및 `.reveal-stagger` 클래스와 `script.js`의 `IntersectionObserver`가 작동합니다.
   *   섹션의 제목과 내용들이 한 번에 나타나지 않고, 약간의 시차(`transition-delay`)를 두고 순차적으로 떠오르면서(Fade-up) 세련된 느낌을 줍니다.
3. **추억 사진첩 슬라이더 (Carousel)**
   *   `#sliderTrack` 내부에 배치된 사진들은 JavaScript의 인덱스 제어(`goTo()`)를 통해 전환됩니다.
   *   사용자가 아무 행동을 하지 않아도 4초마다 다음 사진으로 넘어가며(`setInterval`), 터치 디바이스를 고려해 `touchstart/touchend` 이벤트를 통한 스와이프 로직이 내장되어 있습니다.
4. **긴장감을 주는 카운트다운**
   *   `script.js`의 `tick()` 함수가 1초마다 실행되어 현재 시간과 행사일 간의 차이를 계산합니다.
   *   시간이 변경되는 항목(예: 초)에 한해 찰나의 순간(`.flip` 클래스 부여) 애니메이션이 적용되어 타이머가 째깍거리는 듯한 시각적 효과를 줍니다.
5. **접근성을 고려한 지도 연동**
   *   전 세계 사용자를 위한 구글 지도(iframe)를 기본 제공하며, 국내 사용자들이 내비게이션 및 길 찾기를 더 쉽게 할 수 있도록 '네이버 지도 검색 URL' 버튼을 별도로 배치했습니다. 
6. **마무리 및 참석 회신 (RSVP)**
   *   마지막 `Footer`에는 참석 의사를 전달할 수 있는 버튼(`.rsvp-btn`)이 마련되어 있습니다. 클릭 시 바로 메일 클라이언트가 열리게 되며, 버튼에 마우스를 올릴 때(또는 터치할 때) 배경 색상이 채워지는 인터랙션이 적용되어 있습니다.
